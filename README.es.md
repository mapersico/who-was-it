# 🎬 WhoWasIt

**WhoWasIt** es una aplicación web pública que te ayuda a responder una de las preguntas más comunes cuando ves series de TV o películas:

> **"¿Dónde más he visto a ese actor?"**

Al comparar dos títulos diferentes — películas o series — la aplicación muestra **los actores que aparecen en ambas**, junto con los **papeles que interpretaron**. Está diseñada para ser rápida, simple y accesible sin necesidad de registrarse.

Esto es especialmente útil para espectadores curiosos que quieren respuestas instantáneas sin tener que buscar manualmente en las listas de reparto.

---

## 🧠 Propósito del Proyecto

El objetivo principal de _WhoWasIt_ es proporcionar una interfaz intuitiva para:

- Buscar dos títulos diferentes
- Comparar sus listas de reparto
- Mostrar los actores compartidos, uno al lado del otro
- Mostrar los personajes que interpretaron en cada título

Esta aplicación obtiene datos de una API externa de películas/TV (TMDB) y los procesa a través de un backend Express personalizado para garantizar confiabilidad y formato.

No se recopilan datos de usuarios y no es necesario crear una cuenta. Es una herramienta hecha para todos.
